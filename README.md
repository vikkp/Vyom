# Vyom

**Walk the Sky of the Ancients**

An interactive 3D exploration of Bharatiya (Vedic/Puranic) mythology, anchored in the celestial sphere: Dhruva Tārā, the Saptarishi, and the 27 Nakshatras, with characters and stories linked through a relationship graph.

See [`docs/adr/ADR0001-foundational-architecture-decision.md`](docs/adr/ADR0001-foundational-architecture-decision.md) for the founding architecture decision.

## Stack

- [Vite](https://vite.dev) + React + TypeScript
- [React Three Fiber](https://r3f.docs.pmnd.rs) / [drei](https://github.com/pmndrs/drei) (Three.js)
- [Zustand](https://zustand-demo.pmnd.rs) for state
- [Tailwind CSS](https://tailwindcss.com) for UI
- Target hosting: Cloudflare Pages (`vyomvihar.com`)

## Data model

The content is a directed labelled graph (`src/types/graph.ts`):

- **Nodes** — celestial objects, Nakshatras, deities, sages, characters, story events.
- **Edges** — typed relationships (parent, spouse, guru, boon, astronomical-association, story-link, etc).

The v1 launch graph lives in `src/data/graph.json`, generated by `scripts/build-graph-data.mjs`. Edit the script (not the JSON directly) and regenerate:

```bash
node scripts/build-graph-data.mjs
```

## Development

```bash
npm install
npm run dev      # local dev server
npm run build    # type-check + production build
npm run preview  # preview the production build
```

## Status

Early scaffold: a navigable 3D graph shell (Dhruva Tārā at the centre, Nakshatras + Saptarishi as the primary ring, deities and the Dhruva family as connected clusters), click-to-explore relationships, and search. Camera/navigation model, visual fidelity, and content pipeline are tracked in the follow-up ADRs referenced in ADR0001.
